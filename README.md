# Telegram-бот для продажи книг

Проект реализует Telegram-бота для продажи двух книг и дополнительных внутриботовых продуктов: `книга 1.pdf` и `книга 2.pdf`. Бот ведет пользователя через диагностику, сегментацию, прогрев, консультацию, выбор книги, оплату, выдачу файлов, мини-курс, персональный план и платный ИИ-разбор.

## Что внутри

- Python 3.11+ и `aiogram 3`.
- SQLite без внешней инфраструктуры.
- Цены: одна книга `1500`, комплект `2400`.
- Платежные режимы: `test`, `manual`, `telegram`, `yoomoney`.
- ИИ-консультант: локальный режим по смысловой базе книг и опциональный OpenAI-compatible API через env.
- Админ-команды для цен, текстов, офферов через overrides, рассылок, заказов, пользователей, сегментов и аналитики.
- Рассылки только по согласию пользователя.
- Внутриботовые услуги: лид-магнит, диагностика, мини-курс, платный ИИ-разбор, пакеты «книга + разбор», комплект с бонусами.

## Быстрый запуск

1. Создайте виртуальное окружение:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

2. Установите зависимости:

```powershell
pip install -r requirements.txt
```

3. Создайте `.env` из примера:

```powershell
Copy-Item .env.example .env
```

4. Заполните минимум:

```env
BOT_TOKEN=ваш_telegram_bot_token
ADMIN_IDS=ваш_telegram_id
PAYMENT_MODE=yoomoney
YOOMONEY_CARD_NUMBER=номер_карты
BOOK1_FILE_PATH=книга 1.pdf
BOOK2_FILE_PATH=книга 2.pdf
```

5. Запустите бота:

```powershell
python -m book_sales_bot.main
```

## Docker-Деплой

В проекте есть `Dockerfile`. Стартовая команда внутри контейнера:

```bash
python -m book_sales_bot.main
```

Для деплоя задайте переменные окружения в панели хостинга, а не в репозитории: `BOT_TOKEN`, `ADMIN_IDS`, `PAYMENT_MODE`, `YOOMONEY_CARD_NUMBER`, `AI_API_KEY`, `AI_BASE_URL`, `AI_MODEL`.

PDF-книги не коммитятся в GitHub и исключены из Docker image. Для продакшена нужно либо загрузить `книга 1.pdf` и `книга 2.pdf` в файловое хранилище хостинга и указать `BOOK1_FILE_PATH`/`BOOK2_FILE_PATH`, либо временно добавить файлы в image осознанно, если хостинг закрытый и это приемлемо для вас.

## Если нет подключения к Telegram API

Ошибка вида `Cannot connect to host api.telegram.org:443` означает, что Windows или сеть не может открыть соединение с Telegram API. Проверьте:

```powershell
Test-NetConnection api.telegram.org -Port 443
```

Если `TcpTestSucceeded: False`, включите VPN или настройте proxy. Proxy можно указать в `.env`:

```env
TELEGRAM_PROXY_URL=http://127.0.0.1:8080
TELEGRAM_REQUEST_TIMEOUT=90
```

Для SOCKS-прокси может понадобиться дополнительная зависимость:

```powershell
pip install aiohttp-socks
```

Если запускаете из исходников без установки пакета, используйте:

```powershell
$env:PYTHONPATH="src"
python -m book_sales_bot.main
```

## Проверка сценариев

1. Откройте бота в Telegram и отправьте `/start`.
2. Нажмите `Подобрать книгу`, пройдите мини-квиз.
3. Посмотрите профиль: сегмент, боль, мотивацию, готовность и рекомендацию.
4. Нажмите `Каталог`, выберите одну книгу, комплект или `Комплект + бонусы`.
5. В режиме `PAYMENT_MODE=yoomoney` бот создаст заказ и покажет карту. Отправьте чек файлом в бот, затем админ подтверждает `/admin_confirm ORDER_ID`.
6. Напишите вопрос вроде `Что выбрать, если мне близки мистика и одиночество?` - бот должен ответить как консультант.
7. Откройте `Услуги внутри бота`, проверьте мини-курс и платный ИИ-разбор.
8. После покупки проверьте `/plan`; после покупки разбора проверьте `/deep описание ситуации`.
9. Нажмите согласие на прогрев, затем админом выполните `/admin_warmup_now`.
10. Проверьте отписку командой `/stop`.

## Админ-команды

- `/admin` - статистика и подсказки.
- `/admin_prices` - текущие цены.
- `/admin_set_price book1 1500` - изменить цену книги.
- `/admin_set_price book2 1500` - изменить цену второй книги.
- `/admin_set_price bundle 2400` - изменить цену комплекта.
- `/admin_orders` - последние заказы.
- `/admin_users` - последние пользователи.
- `/admin_stats` - события воронки.
- `/admin_segments` - распределение пользователей по сегментам.
- `/admin_set_optin USER_ID on|off` - вручную изменить согласие на рассылку.
- `/admin_confirm ORDER_ID` - подтвердить ручную оплату и выдать файлы.
- `/admin_broadcast текст` - отправить сообщение пользователям с согласием на рассылки.
- `/admin_warmup_now` - отправить следующий прогрев всем согласным пользователям.
- `/admin_offer product_id текст` - изменить оффер продукта без редактирования JSON.
- `/admin_text key текст` - задать текстовый override.
- `/admin_texts` - список override-текстов.

## Платежи

`PAYMENT_MODE=test` подходит для проверки: оплата подтверждается кнопкой в боте.

`PAYMENT_MODE=manual` создает заказ и показывает реквизиты из `MANUAL_PAYMENT_DETAILS`. После поступления денег админ подтверждает заказ командой `/admin_confirm ORDER_ID`.

`PAYMENT_MODE=yoomoney` работает как ручной внутриботовый сценарий оплаты: бот показывает карту/реквизиты, пользователь отправляет чек в бот, бот уведомляет админов, админ подтверждает заказ.

`PAYMENT_MODE=telegram` использует Telegram Payments. Для него нужен `TELEGRAM_PROVIDER_TOKEN` от платежного провайдера, подключенного в BotFather.

## Персональные данные и секреты

Секреты не хардкодятся. Токены, ключи ИИ, платежные реквизиты и пути к файлам задаются через `.env`.

В SQLite хранится минимальный набор данных: Telegram ID, username, имя, согласие на рассылку, теги интересов, заказы и покупки. Рассылки идут только пользователям, которые дали согласие; `/stop` снимает согласие.

## Внутриботовые продукты

- `book1` - `Ведьма чёрной воды`, 1500 руб.
- `book2` - `Сборник рассказов`, 1500 руб.
- `bundle` - комплект из двух книг, 2400 руб.
- `bundle_bonus` - комплект с бонусами внутри бота, 2400 руб.
- `deep_reading` - платный ИИ-разбор ситуации, 900 руб.
- `book1_plus_reading` - первая книга + разбор, 2200 руб.
- `book2_plus_reading` - вторая книга + разбор, 2200 руб.
- `mini_course_plus` - мини-курс внутри бота, 600 руб.

## Что нужно заполнить перед реальным запуском

- Telegram Bot Token.
- Telegram ID админов.
- Платежный режим и данные провайдера.
- Реквизиты для ручной оплаты, если используется `manual`.
- Ключ и модель ИИ, если нужен внешний AI вместо локального консультанта.
- Финальные тексты прогрева, если нужно изменить авторский тон.
- Для настоящей API-интеграции ЮMoney: shopId/кошелек, OAuth/client credentials, redirect/notification URL и выбранный юридический сценарий приема платежей.
